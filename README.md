# Nikita Zakharenko · Portfolio

Лендинг-резюме на React, TypeScript, Vinext и Three.js. Четыре горизонтальных экрана, английская и русская версии, четыре 3D-модели (робот, хранилище данных, граф сервисов, переписка) и переходы между ними.

Сборка, публикация и подключение домена описаны в [DEPLOY.md](./DEPLOY.md).

## Локальный запуск

Нужны Node.js 22.13.0 или новее и npm. Откройте терминал в папке проекта:

```sh
npm run install:ci
npm run dev
```

Откройте адрес, который напечатает сервер. По умолчанию это `http://127.0.0.1:5173/`.

Архив содержит исходники. Зависимости устанавливаются первой командой; `node_modules`, сборка, локальные настройки и Git-история в архив не включены. Для установки зависимостей нужен интернет.

## Сборка и проверка

```sh
npx tsc --noEmit
npm run build
npm start
```

`npm start` запускает собранный Cloudflare Worker локально. Используйте адрес из вывода команды. Для работы этой страницы не нужны API-ключи, база данных или внешние 3D-файлы: модели создаются программно.

## Что менять

- `app/page.tsx`: тексты EN/RU, контакты, опыт, горизонтальная навигация.
- `app/scene.ts`: модели, материалы, освещение и переходы.
- `app/blob.tsx`, `app/three-loader.ts`: React-обёртка сцены и ленивая загрузка Three.js.
- `app/globals.css`: цвета, шрифты, размеры и адаптивная вёрстка.
- `app/layout.tsx`: заголовок, метаданные и подключение шрифтов.
- `public/Nikita-Zakharenko-CV.pdf`: скачиваемое резюме.
- `.openai/hosting.json`: идентификатор текущего проекта Sites.

Сохранены конфигурация и скрипты исходного проекта, необходимые для сборки. Отдельные каталоги `components`, `db` и `examples` входят в шаблон; текущая страница не использует базу данных.

## Управление

Колесо мыши переключает экраны, если текущий раздел не требует вертикальной прокрутки. Также доступны горизонтальные жесты, клавиши влево/вправо и Home/End из любого места страницы, ссылки в меню, индикатор экранов и стрелки внизу. Переключатель «Анимация» внизу слева включает и отключает движение. Выбранный язык запоминается. Системная настройка уменьшения движения учитывается автоматически.
